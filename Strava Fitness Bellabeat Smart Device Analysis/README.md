# Bellabeat Smart Device Fitness & Wellness Analysis

## Project Overview

Analyzed smart-device fitness and wellness data using **Python, SQL, and Power BI** to identify patterns in user activity, sleep, sedentary behavior, heart rate, and device engagement.

## Business Objective

Understand user behavior and identify opportunities for **personalized wellness features and improved user engagement**.

## Tools & Technologies

* Python — Pandas, NumPy, Matplotlib, Seaborn
* SQL — Data cleaning, validation & analysis
* Power BI — Dashboard & visualization
* SQLite — Data management

##  Key Findings

* **58.3%** of recorded days were Lightly Active.
* Steps and calories had a **0.56 correlation**.
* Average logged sleep was **7.0 hours**.
* **44.1%** of recorded sleep days were below 7 hours.
* Average device tracking was **26.2 days out of 31**.
* Steps and sleep showed a weak correlation of **-0.19**.
* Recorded sedentary time averaged **15.9 hours/day**.
* Weight data was limited to **8 users**.

##  Business Insights

* Users show consistent device engagement but could benefit from increased activity.
* Sleep behavior provides an opportunity for personalized wellness engagement.
* Sedentary behavior can be addressed through timely movement reminders.
* Combining activity, sleep and heart-rate data can support personalized user insights.

##  Recommendations

* Introduce personalized activity and movement nudges.
* Provide sleep goals and sleep-progress insights.
* Use prolonged inactivity alerts to encourage movement.
* Combine multiple health signals for personalized recommendations.
* Improve automatic health-data and smart-scale integration.
* Track engagement and retention KPIs to evaluate feature effectiveness.

##  Project Components

* `Python/` — Exploratory Data Analysis
* `SQL/` — Data cleaning and analysis
* `PowerBI/` — Interactive dashboard
* `Presentation/` — Project presentation

## Limitations

The dataset represents a limited sample of wearable-device users. Weight/BMI data was available for only a small subset, and correlations should not be interpreted as causal relationships.
