# Mutual Fund Performance & Risk Analytics

##  Project Overview

This project analyzes **814 mutual fund schemes** to understand historical performance, risk, risk-adjusted returns, expense ratios, and Assets Under Management (AUM).

The objective was to move beyond return-based comparisons and provide a broader analytical view of mutual fund performance using **Python and Power BI**.

---

##  Business Problem

How can mutual fund schemes be compared using multiple performance and risk indicators rather than relying only on historical returns?

The analysis focuses on:

* Return
* Risk
* Sharpe Ratio
* Sortino Ratio
* Expense Ratio
* AUM
* Scheme-level comparison

##  Key Findings

| Metric                |     Result |
| --------------------- | ---------: |
| Mutual Fund Schemes   |    **814** |
| Average 3-Year Return | **18.72%** |
| Average Expense Ratio |  **0.75%** |
| Average Sharpe Ratio  |   **1.25** |
| Average Sortino Ratio |   **2.77** |
| Average Risk          |   **4.50** |

### Key Business Insights

* Mutual fund performance varies considerably across schemes.
* Historical return alone does not provide a complete view of fund performance.
* Risk-adjusted metrics provide additional context when comparing schemes.
* Expense ratio is an important factor when evaluating the cost associated with a fund.
* AUM provides information about fund scale but should not be treated as a direct measure of performance.
* Combining return, risk, cost and AUM creates a more comprehensive analytical framework.

---

##  Business Recommendations

* Use multiple metrics instead of historical return alone when screening schemes.
* Monitor Sharpe and Sortino ratios alongside returns.
* Investigate whether higher-cost schemes demonstrate stronger historical performance or risk-adjusted results.
* Track AUM separately as a scale indicator.
* Periodically refresh performance and risk metrics to monitor changes over time.

---

## Business Value

The dashboard provides a consolidated view of mutual fund performance and risk, helping analysts conduct comparative research and identify different performance/risk profiles.

The project is designed for **historical analysis and analytical demonstration**, not future-return prediction or personalized investment recommendations.
