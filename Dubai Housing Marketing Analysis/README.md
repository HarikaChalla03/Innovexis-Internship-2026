# Business Problem :
Real-estate businesses need to understand how location, property size, bedroom count and property age influence housing prices in order to improve pricing, marketing and investment decisions.


# Business Objective :
Analyze 50K property listings to identify
Pricing patterns
Affordable vs premium locations
Price-per-square-foot differences
Property demand by bedroom count
Relationship between property size and price
Impact of property age on pricing
Potential investment segments

# Tools
Power BI | DAX | Power Query | Excel/CSV | Data Modeling

# Key Metrics
50K - Property Listings
224.83K - Average Property Value
113.31 - Average Price/Sq.Ft.
3.5 - Average Bedrooms

# Key Findings
1. Location Premium : Urban properties command higher price per square foot
2.  Affordability : Suburban properties are more affordable
3. Space vs Price : Rural properties show relatively lower pricing
4. Demand : 3-bedroom and 5-bedroom properties have the highest demand in this dataset
5.  Property prices generally increase with bedroom count
6. Age Pattern : Older properties appear more expensive in this dataset

# Business Investigation
1. Which locations command the highest property prices?

Urban properties show the highest price per square foot, while suburban properties have lower pricing.

Business implication : Location appears to be an important pricing differentiator.

2. Where can buyers obtain more space at relatively lower prices?

The dashboard identifies rural properties as offering larger space at relatively lower prices, while suburban properties represent the more affordable area based on average property price.

Business implication : Different customer segments may value different trade-offs:
Urban → Location premium
Suburban → Affordability
Rural → Space/value relationship

3. Which property configurations appear most frequently in the market?

3-bedroom and 5-bedroom properties as dominant demand categories, while 2–4 bedroom properties collectively represent the more common mid-sized segment.

Business implication : Developers and real-estate marketers could use bedroom-level demand patterns when evaluating:
New development mix
Marketing campaigns
Inventory planning
Target customer segments

4. Does newer automatically mean more expensive?

 No. Analysis shows relatively higher prices for Very Old and Old properties, with Very Old properties having the highest pricing.


# Business Recommendations
Recommendation 1 — Segment marketing by location
| Segment  | Possible positioning     |
| -------- | ------------------------ |
| Urban    | Premium/location-focused |
| Suburban | Affordability/value      |
| Rural    | Larger space/value       |

Recommendation 2 — Focus inventory analysis on mid-sized properties
Since 2–4 bedroom properties are more common in the dataset, developers and marketers should closely monitor this segment for:
Inventory planning
Customer demand
Pricing
Marketing campaigns

Recommendation 3 — Don't use property age alone for pricing decisions
The unexpected age-price relationship means property age should be analyzed together with:
Location
Property size
Bedrooms
Price per square foot
before making pricing decisions.

Recommendation 4 — Use price per square foot as a key comparison KPI
Total property price can be misleading because properties have different sizes.
Therefore, price per square foot provides a more comparable measure across locations.

Recommendation 5 — Investigate potential value opportunities
Rural properties show a larger-space/lower-price relationship in the current analysis.
A real-estate business could investigate these properties further rather than immediately labeling them as undervalued.
