#  PhonePe Pulse Data Visualization & Exploration

##  Project Overview

This project analyzes **PhonePe Pulse digital payment data across India** using **Power BI** to understand transaction trends, user adoption, payment categories, state-level performance, and district-level variations.

The dashboard converts large-scale digital payment data into interactive business insights that can support **regional strategy, merchant expansion, customer engagement, and payment-product decisions**.

---

##  Business Objective

The objective of this project is to answer key business questions such as:

* Which states generate the highest transaction volume?
* Which states generate the highest transaction value?
* Are the highest-volume and highest-value states the same?
* Which states are growing the fastest?
* How is the payment-category mix changing?
* Which districts underperform within high-performing states?
* Where are potential opportunities for further investigation and growth?

##  Key Findings

1. The analyzed PhonePe ecosystem contains **72B transactions and 373M registered users**, demonstrating the scale of digital-payment activity covered by the dashboard.

2. **Maharashtra** has the highest transaction volume at approximately **10.39B transactions**.

3. **Telangana** has the highest transaction value in the dashboard at approximately **₹165.2T**.

4. The highest transaction-volume state and highest transaction-value state are **different**, showing why businesses should monitor both **transaction count and transaction value**.

5. The dashboard reports strong overall growth, with **145.60% CAGR and 271.85% YoY growth** across the analyzed data.

6. The analysis compares **P2P, merchant, recharge/bill-payment and financial-service transactions** to understand payment behaviour.

7. District-level analysis highlights **underperforming districts within high-performing states**, helping identify areas that require further investigation.

---

##  Business Insights

### 1. Transaction Volume vs Transaction Value

Transaction frequency and monetary value provide different perspectives of market performance.

Businesses should therefore monitor:

**Transaction Volume + Transaction Value + Average Transaction Value**

rather than relying on a single KPI.

### 2. Regional Differences

Digital-payment activity varies significantly across states.

This indicates that customer behaviour, merchant adoption and payment usage should be investigated at a **regional level**.

### 3. Growth Opportunities

CAGR and YoY growth can help identify markets that are expanding rapidly and may require additional business attention.

### 4. Payment Behaviour

Tracking P2P, merchant and recharge/bill-payment categories helps identify changes in how customers use digital payments.

### 5. District-Level Opportunities

State-level performance can hide weaker districts. District-level drill-down provides a more detailed view of localized performance.

##  Business Recommendations

### 1. Monitor Volume and Value Separately

Use transaction count and transaction value together to understand both payment frequency and monetary contribution.

### 2. Develop Regional Strategies

Use state-level performance to support region-specific customer acquisition, merchant onboarding and engagement strategies.

### 3. Investigate High-Growth Markets

Use CAGR and YoY growth to identify markets that may require additional investment and business investigation.

### 4. Improve Underperforming Districts

Drill down into weaker districts and investigate factors such as merchant availability, customer adoption and transaction frequency.

### 5. Monitor Payment Mix

Track changes in P2P, merchant, recharge/bill-payment and financial-service transactions to understand evolving customer behaviour.

### 6. Build a Continuous Monitoring Dashboard

A recurring dashboard could monitor:

**Users → Transactions → Transaction Value → Average Transaction Value → Payment Category → State → District → Growth**
